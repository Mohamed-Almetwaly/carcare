📊 لوحة تحكم العملاء (/dashboard/)
ملخص الحساب: عرض معلومات الحساب والحجوزات
إدارة السيارات (My Garage): إضافة وتحديث سيارات الزبون (الماركة، الموديل، السنة، رقم اللوحة)
تتبع المواعيد: مراجعة أو إلغاء الحجوزات القادمة
الملف الشخصي: تحديث البيانات وتغيير كلمة المرور
🔧 لوحة تحكم الإدارة (/admin/)
لوحة المعلومات: إحصائيات حية (إجمالي الحجوزات، الإيرادات، عدد العملاء والسيارات)
إدارة الحجوزات: تحديث حالة الحجز (معلق / قيد التنفيذ / مكتمل / ملغى) عبر AJAX
إدارة الخدمات والعملاء: إضافة وتعديل وحذف الخدمات، وعرض قائمة العملاء وسياراتهم
الرسائل الواردة: مراجعة استفسارات العملاء من نموذج الاتصال
🛡️ الأمان والتقنيات المستخدمة
المجال	التقنية
الخادم	PHP 8.2+ مع البرمجة الموجهة للكائنات (OOP)
قاعدة البيانات	MySQL مع علاقات Foreign Keys محكمة
الحماية من الثغرات	Prepared Statements (حماية من SQL Injection)
تشفير كلمات المرور	خوارزمية Bcrypt الآمنة
